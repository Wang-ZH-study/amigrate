# 迁移验收清单（人读版）

> 配套规格：[`specs/migration-spec.toml`](../specs/migration-spec.toml)（机器判卷，唯一来源）
> 判卷脚本：[`tools/check_spec.py`](../tools/check_spec.py)
> 判卷命令：`python tools/check_spec.py --check-spec`（查证据齐不齐）→ `python tools/check_spec.py --judge runs/.../result.json`（判 pass/fail）

每一层都必须给出"证据形式"与"谁判"；**没有证据的一律算未通过**，不许口头确认。

## 第 1 层：拓扑与工作点

| # | 检查项 | 判据 | 证据形式 | 谁判 | 本轮 |
|---|---|---|---|---|---|

## 判定总则

| 规则 | 含义 |
|---|---|
| 缺项即失败 | 任一必需证据缺失 → 本次迁移不得判为通过 |
| 任一项 fail 即失败 | 所有 active 指标必须同时达标 |
| out-of-scope 不算 pass | 未覆盖的层只记录，不参与通过判定 |
| 结论只有三种 | 通过 / 有条件通过（列出未覆盖层与残留风险）/ 未通过 |
| 可复现 | 判卷命令 + 输入文件路径写进报告，他人可重跑 |

## 蒙卡 300 点（2026-11-26，Pelgrom Vt 失配）

- 口径：σ(ΔVt)=Avt/√(W·L)，Avt：n33 9.5、p33 3.5 mV·µm；每个管独立抽样，300 次。
- 实现：每管栅极串一个 ΔV_i ~ N(0,σ_i) 电压源（等价 Vt 失配），每次运行跑 AC + op。

## β 失配与噪声（2026-11-26）

- **β 失配**：从模型参数合成（公式见 `docs/porting/lut-provenance-and-validation.md` §9），已写入 LUT 的 beta0/beta1 列；3σ 带宽：n33 0.18–1.95%、p33 0.18–1.26%（随面积变化），远小于原来默认的 ±5%。
- **噪声（Spectre 仿真）**：OPA_D v2 输入参考噪声 1Hz 6.18µV/√Hz、10kHz 79.4nV/√Hz、1MHz 13.8nV/√Hz；单管 n33 热噪声底 14.1nV/√Hz、1/f 系数 B=8.76e-11 V²·Hz。
- **诚实结论**：此前 LUT 的 inoise 列为公式推导，实测低 4–20 倍，**不能用于噪声预算**；已把真实仿真与拟合系数留档（`runs/2026-11-26-noise/`），后续按 `4kTγ/gm + Kf/(W·L)/f` 更新表。
