# AD633 类乘法器迁移可行性（用户设想，2026-11-25）

## 先划清概念

AD633 是 **4 象限模拟乘法器（Gilbert 单元）**：±15V 供电、差分 X/Y 输入（10V 满量程）、求和输入 Z、1% 线性度、1MHz 带宽。

"设计一个类似 AD633 的乘法器再迁移"要分清两件事：
1. **重新设计**一个 1.8V 的 Gilbert 乘法器（拓扑/指标都要改）；
2. **迁移**：把它从源 PDK 搬到 13mmrf（我们的流水线干的事）。

AD633 原样搬到 1.8V 不可能——±15V 的摆幅/头寸在 1.8V 下不存在；但**同拓扑的 1.8V 版本**可以做。

## 结论：方法上可行，但属于"设计 + 迁移"，不是"器件替换"

我们的工具链能直接复用：
- LUT（18ee 源表 + 13mmrf_io18 目标表）→ 逐管解尺寸；
- SKILL 换器件 + 写尺寸（已验证 8/8）；
- 网表 + Spectre（DC/AC/瞬态）验证；
- 可行性判定 F0–F4（电压余量、gm/Id 可达、W 可实现）。

## 关键风险（按严重度）

| 风险 | 说明 | 对策 |
|---|---|---|
| **头寸** | Gilbert 单元纵向叠 3 个 Vdsat（尾电流源 + 输入对 + 负载），1.8V 下每管只剩 ~0.4–0.5V | 先用 F3 判据扫；必要时用 1.8V IO 器件 + 低压 cascode |
| **线性度** | 乘法器靠差分对的指数/平方律特性，短沟道 + 小摆幅会恶化线性度 | 加长 L、加大 W、用源极退化；以瞬态/双音测试验证 |
| **失配/失调** | 乘法器对输入对失配极敏感（offset、增益误差） | 需要 13mmrf 失配模型 + 蒙卡；当前表 avt 列仍是 pending，必须先补 |
| **带宽** | 1.8V 下 gm 受限，1MHz 级目标可行，但要做偏置电流预算 | 与 08 的偏置重分配一起做 |

## 建议的推进顺序

1. 你定目标规格：供电 1.8V、X/Y 输入范围、带宽、线性度、功耗；
2. 在**源 PDK（smic18ee 或 13mmrf）**里画一版乘法器原理图（Gilbert 单元 + 偏置 + 输出级）；
3. 用现成流水线迁移到 13mmrf（n33/p33），逐管解尺寸；
4. 验证：DC 传输（X 固定扫 Y）、瞬态乘法（双正弦）、线性度/THD、蒙卡失调；
5. 与 AD633 的指标做"缩放后"对照（不是原样对标）。

## 需要补的前置

- 13mmrf 的 **avt/失配参数**（当前 LUT 里 `avt_src=pending`）——乘法器必须要；
- 蒙卡仿真脚本（MC 跑 offset/gain error）；
- 目标指标表（spec）——否则"可行"没有判据。
