# 吉尔伯特单元乘法器可行性评估（13mmrf，1.8V）

> 2026-11-25 ｜ 关联：ADR 0002（1.8V 方案 B）、05.7（F0–F4）、08（重定尺寸）、11 号工单
> 结论先行：**可行（有条件）**——拓扑本身能放进 1.8V，但线性度/失配/头寸三件事必须提前定，否则会做成"能乘但精度差"的电路。

## 一、拓扑与 1.8V 头寸（最关键）

经典吉尔伯特单元（AD633 内核）纵向叠三层：

```
VDD
 ├─ 负载（电阻或电流镜）
 ├─ 开关四管（Y 输入，差分对，尾节点在 X 支路）
 ├─ 输入差分对（X 输入，V→I 转换）
 └─ 尾电流源
VSS
```

1.8V 下的静态头寸预算（n33/p33，Vth≈0.6V，Vdsat≈0.2–0.25V）：

| 层 | 最小 Vds | 说明 |
|---|---|---|
| 尾电流源 | 0.25 V | 饱和区 |
| 输入对（Vds） | 0.25 V | 饱和区 |
| 开关四管（Vds） | 0.25 V | 饱和区，留裕量 |
| 输出节点 CM | ≥0.2 V | 单端输出的摆幅余量 |
| **合计静态占用** | **≈0.95 V** | 剩约 0.85 V 给摆幅/CM 选择 |

**判断**：能放进 1.8V，但**输出摆幅只剩约 ±0.3–0.4V**（差分），且输入共模必须选在 1.0–1.2V 附近。**不要加 cascode**（再叠 0.2V 就爆）。

## 二、线性度（第二关键）

- 吉尔伯特单元的乘法来自差分对的 `tanh` 特性，**小信号区才线性**：
  - 输入对差分输入摆幅大致 ≤ 2×Vdsat（约 ±100–150 mV）时线性度 ~1%；
  - 超过后进入开关区，乘法功能还在，但失真快速上升。
- AD633 的 ±10V 满量程在 1.8V 下不可能复现；**必须重新定义输入范围**（建议 ±0.2–0.3V 差分）。
- 想扩线性范围：X 输入加源极退化（牺牲增益）、或用四分之一平方（quarter-square）拓扑（复杂度上升）。

## 三、失配与失调（决定"乘法精度"）

- 乘法器的失调主要来自：输入对 Vth 失配、开关四管失配、负载失配；
- 1.8V 下过驱动小（~0.2V），失配相对影响更大；
- **前置条件**：13mmrf 失配模型（`mismod`/`atox`/`axl`）+ 蒙卡脚本。当前迁移版 LUT 的 `avt` 列仍是 `pending`，必须先补，否则"精度"无法验证。

## 四、带宽

- 目标若对标 AD633（1MHz 级）→ 容易；若要做到 10MHz 以上，输出极点（Rload·Cload）和开关节点电容是瓶颈；
- n33/p33 的 fT 在 1.8V 下有限，建议先按 **1–5MHz** 定目标。

## 五、输出形式

- 差分电流输出 → 需电流镜负载转单端，或直接差分电压输出；
- 若必须单端电压输出（像 AD633 的 W 引脚），要多一级 diff→single（多 0.2–0.3V 头寸 + 功耗）；
- 建议第一版**先做差分输出**，把单端转换留到第二版。

## 六、我们现有资产能不能直接支持

| 资产 | 状态 | 是否够用 |
|---|---|---|
| 13mmrf IO LUT（n33/p33，5mV 网格） | ✅ | **不够**：Vsb 只扫到 0.4V，吉尔伯特单元里叠层器件 Vsb 可达 0.8–1.0V，**需扩 Vsb 到 1.2V** |
| 反解器/可行性 F0–F4 | ✅ | 可用，但 F3 要加"叠层总头寸"判据 |
| SKILL 换器件 + 写尺寸 | ✅ | 可用 |
| 失配/蒙卡 | ❌ pending | **必须先补** |
| AC/DC/瞬态/THD 测量台 | ✅ | 可复用；乘法器要加"DC 传输 + 双音/瞬态乘法"测试台 |

## 七、结论与建议

**可行（有条件）**，条件按优先级：

1. **定规格**：供电 1.8V、X/Y 输入范围（建议 ±0.2–0.3V 差分）、输出形式（先差分）、带宽（1–5MHz）、线性度（如 1% FS）、功耗；
2. **扩 Vsb 网格**（到 1.2V）重扫 n33/p33 表——这是明天动手前的第一件事；
3. **补失配参数 + 蒙卡**（否则精度不可判）；
4. 先用**最小可测拓扑**（尾源 + 输入对 + 开关四管 + 电阻负载）跑 DC 传输与瞬态乘法，再加输出级/偏置。

**不建议**：一上来对标 AD633 的 10V 满量程/±15V 指标；那是另一个产品，不是 1.8V 可实现的迁移目标。
