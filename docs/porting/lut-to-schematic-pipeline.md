# 从 LUT 到"可仿真原理图"：两段式流水线

> 2026-11-25 ｜ 关联：工单 05（表/反解）、07（映射）、08（重定尺寸）
> 回答："两张表能不能帮我们定 W/L，再交给 SKILL 生成可仿真原理图？"

## 一句话结论

**能，但必须分成两段、中间加一道电路级核对**：

```
① 表 → 逐管候选 (L,W)        ② 电路级 DC 迭代 ≈ 候选尺寸在真实拓扑下是否成立
                              ↓
③ 尺寸表（inst → w/l/nf/m）  ④ SKILL 在 Virtuoso 里换器件+套尺寸 → 原理图
                              ↓
⑤ 导出网表 → Spectre .op/DC/AC → 不对就回 ②
```

**表定的是"起点"，不是"终值"**：逐管解必然与 KCL 打架（同一支路多管共享电流），所以 ③ 之前必须有 ②。

## 两段各自负责什么

| 段 | 工具 | 输入 | 输出 | 不负责 |
|---|---|---|---|---|
| ① 定尺寸初值 | `tools/solve_lw.py`（表反解） | 源工作点 (Id, gm/Id, self_gain) + 目标 PDK LUT | 每管候选 (L, W_total, Vgs) | 电路一致性、寄生、匹配 |
| ② 电路级核对 | 网表 + Spectre DC（07/08） | 候选尺寸 + 目标器件映射 | 收敛后的工作点与修正量 | 版图、PVT |
| ③ 尺寸表 | 本流水线的数据契约（见下） | ② 的结果 | `sizing_table.csv` | — |
| ④ 原理图生成 | Cadence SKILL（`skill/apply_sizes.il` + `conv.config`） | 尺寸表 + 源库 + 目标 PDK | 目标库 schematic + symbol | 性能、版图、引脚重连 |
| ⑤ 验证 | ADE + Spectre | ④ 导出的网表 | `.op/DC/AC` 结果 | signoff |

## ③ 的数据契约：`sizing_table.csv`

一行一个实例，**列名固定**（SKILL 与 Python 共用）：

```
inst,dev_src,dev_tgt,L_um,W_um,nf,m,vsb,vds,vgs,note
M1,p18e2r,p12_mis_ckt,0.50,2.94,1,1,0.254,0.4,0.478,candidate
M3,n18e2r,n12_mis_ckt,0.50,0.75,1,1,0.0,0.4,0.465,candidate
...
```

规则：
- `W_um` 是**总宽**；摊成 `nf`（指数）与 `m`（并联）由 SKILL 按目标 CDF 能力做，写回 `w` 单指宽；
- `dev_tgt` 必须能在目标 PDK 的 Library Manager 里打开（`dbOpenCellViewByType` 成功），否则该行报错、不静默跳过；
- 未通过电路级核对的实例标 `note=needs_resize`，SKILL 只写入不保证性能。

## ④ SKILL 侧做什么（已给模板）

脚本：`skill/apply_sizes.il`（本仓库，纯 SKILL，无外部依赖）
配套：`skill/conv.config`（源→目标器件映射模板）

流程：
1. 源库 `dbCopyCellView` 复制到目标库（SKILL 原地改，不复制会改坏源库）；
2. `abConvertComponentParamsHier("conv.config")` 换器件 master（18ee → 13mmrf）；
3. `abApplySizes("sizing_table.csv")`：按实例名查表 → `dbSet` w/l/nf/m → 调 CDF 回调；
4. `schCheck` + 保存；导出网表，交 ⑤。

**模板的三条硬边界**（已在脚本注释里写死）：
- 不重连引脚（引脚本数变化就断，必须网表 diff）；
- 只写尺寸，不判断尺寸好坏；
- 目标 PDK 的 CDF 参数名要用 `paramMap` 配置，不假设两套 PDK 同名。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 逐管尺寸在电路里不成立（KCL 打架） | ② 电路级 DC 必须做；不做就等于把错误焊进原理图 |
| 引脚不匹配导致错连 | 先跑 1 个 MOS + 1 个电阻试点；网表 diff 逐条核 |
| 总宽摊不成合法 nf/m（单指宽越界） | 在 ③ 的生成脚本里加约束；摊不下就改 L 或并联 |
| 13mmrf core 1.2V 与 1.8V 供电不匹配 | 05.2 先决策；表里 core/IO 器件分开解 |
