## 6. 已知问题与操作注意（重要）

1. **`virtuoso -nograph` 退出会挂起**：工作完成后进程常不退出（Calibre 服务/锁），用 `timeout 180 virtuoso -nograph < x.il`；文件已写出即可，不要等进程。
2. **GUI Virtuoso 会话会占锁**：VM 桌面若开着 Library Manager/原理图，headless 读写 `port_pilot` 可能卡住；先关闭 GUI 里的该 cellview，或换库副本。
3. **SKILL 写参数**：对 CDF 参数 `dbSet` 静默失败，必须用 `dbReplaceProp inst "w" 'string "9u"`；指数参数叫 `fingers`（无 `nf`）。
4. **SKILL 读 CSV 不可靠**：`lineread/readLine/gets` 都有问题；要数据就由 Python 生成 `.il`（硬编码 list）或走 CLI。
5. **SKILL 保留字**：不要用 `t` 作循环变量（protected）。
6. **运行脚本要 LF**：Windows 写的 `.scs/.sh` 先 `sed -i 's/\r$//'`，否则 VM bash/spectre 报错。
7. **蒙卡口径**：当前只含 Vt 失配（栅极串 ΔV 源，σ=Avt/√WL），不含 tox/β 与 SR；不要对外说"全统计模型 100% 良率"。
8. **噪声口径**：LUT 的噪声列现在是实测拟合（κ 校准），低频 1/f 依赖 B_ref；改版后需用 `tools/noise_report.py` 复核。
9. **PVT 最坏角余量薄**：UGF 只比目标高 9.7%，量产建议留工艺漂移余量。
10. **不入库**：PDK、`runs/*/raw`、波形等；只提交 README/csv/结论。

### 9.2 CMRR / PSRR / offset 角集（`runs/2026-11-26-cpo/`）

45 工况（5 process × 3 VDD × 3 temp），每工况 4 个分析（Ad/Acm/PSRR/offset）：

| 指标 | 最小 | 最大 | 均值 |
|---|---|---|---|
| CMRR | 48.38 dB | 75.32 dB | 61.14 dB |
| PSRR | −34.41 dB | +4.27 dB | −18.26 dB |
| offset | −89.97 mV | +90.18 mV | 0.14 mV |

- CMRR 极值说明：输入端/尾电流失配对共模抑制影响大，最坏 48dB 属正常范围但偏低；
- **PSRR 为负**（电源增益 >1）是该拓扑（VBP 由 Rb 对地偏置）的固有弱点，与前期结论一致；
- **offset 极值 ±90mV 偏大，疑似最坏角输出接近饱和导致**，报告口径已注明，正式验收前需用开环 DC 扫描复核。
