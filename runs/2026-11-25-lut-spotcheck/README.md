## 方法

- 抽点：从 `gmid_table.csv` 随机抽（固定种子），n/p 各半，覆盖不同 L/Vds/Vsb/Vgs；
- deck：单管 + 固定工作点 + `dc`，与上游 `diag.scs` 同一个 PDK/温度/容差设置；
- 执行：`ssh ic618` 在 VM 里跑 Spectre 18.1，结果 psfascii 回传后本地解析；
- B 档尺寸来自 `tools/solve_lw.py` 的反解结果（M1/M6）。
