## 3. 对比：表格里的公式 vs 仿真

- LUT 公式只算沟道热噪声 sqrt(4kTγ/gm)；M1/M2 输入对（W=244.2µm）的公式热噪声 ≈ **3.24 nV/√Hz**；
- 单管仿真热噪声底 ≈ **14.14 nV/√Hz**（比公式高 4.4×，模型含更多噪声源）；
- OPA 仿真在 10kHz 为 **79.4 nV/√Hz**、1MHz 为 **13.8 nV/√Hz**，1/f 噪声在低频占主导。

## 结论

1. 表格里 inoise 列是**公式推导**，明显低估（未含 1/f 与偏置网络噪声）→ 不能用于噪声预算；
2. 已拿到真实仿真值（OPA 与单管），并拟合出单管 1/f 系数 B；
3. 若要替换表格噪声列：用 N²(f)=4kTγ/gm + Kf/(W·L)/f 形式按面积缩放，Kf 由本实验拟合。
