## 方法

1. 目标取自 sizing_D.csv 的 (Id, gm/Id, Aint, Vsb, L)；
2. gm = (gm/Id)·Id，self_gain = 10^(Aint/20)；
3. 对每个 Vds 切片反解，取 self_gain 残差最小的候选——**选 Vds 不看原 W**，避免循环论证；
4. 原 W 只用于事后对比。
